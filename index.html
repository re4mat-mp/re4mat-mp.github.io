    Hi, I'm Matias. I build with Claude Code: small teams of agents with one craft each, reviewers that never wrote the code they review, and guards that keep a person in the loop before anything ships.

    Every piece here opens: each one has a page you can click through.

    The pieces, in order

    1. The setup guide (箱, the box): my Claude Code setup and the habits behind it. Agents with one craft each, reviewers that never wrote the code, guard hooks, and a memory that loads whole. Open the box · the repo.
    2. The factory (工場): how I run the big jobs. A script cuts the work, agents read in parallel, and code checks every answer. The page runs an example job, with invented numbers. See it run.
    3. The agent board (匠, craft): a board to watch a crew of agents grow, rebuilt with an invented crew. Seven crafts, XP that only one command can write, a Lead whose level is the crew's average. Open the board · the repo.
    4. The travel book (旅, a journey): a Kindle travel book written with Claude, the method shown on an invented trip. Turn the pages · the repo.
    5. The house (家, a house): two floor plans and a few still renders turned into a 3D house you can orbit, walk through and watch at any hour, in the browser. Built by two Claude Code agents against one spec. Walk the house · the repo.
    6. The game (航海, a voyage): a Game Boy-style RPG where every pixel is drawn by code. No ROM, no emulator, no image files; it plays on a phone too. An unofficial fan game. Play it · the repo.
